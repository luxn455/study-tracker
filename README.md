Study Tracker v2

Description

Study Tracker v2 is a simple Python program that analyzes study-time data stored in a JSON file.

The program calculates the total study time, average study time, and finds the days when the study time was 60 minutes or more.

Features

Calculate total study time

Calculate average study time

Find days with 60 minutes or more of study time

Load study data from a JSON file

Handle missing files and empty data

File Structure

main.py - The main file used to run the program

study_utils.py - Contains functions for calculating and analyzing study time

study_data.json - Stores study-time data as key-value pairs
